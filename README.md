# FORGEXR

FORGEXR is an immersive educational universe prototype built with React, Vite, and Three.js.

## Quick start

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Preview

```bash
npm run preview
```

## GitHub Pages deployment
The repository includes a GitHub Actions workflow for publishing the `dist` output to the `gh-pages` branch.

## Notes
- Desktop exploration mode is supported through mouse/keyboard interaction.
- The prototype includes a hub world and the Crystal Caverns / Crystal Lab vertical slice.
- The curriculum is structured for expansion through data-driven world definitions.
